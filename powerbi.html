Curriculum · Beginner Level

Course Modules

5 structured modules + a capstone project. Intermediate and Expert levels coming soon.

01
Power BI Fundamentals
Week 1–2 · 6 lessons
  • What is Business Intelligence and why Power BI?
  • Installing Power BI Desktop and navigating the interface Hands-on
  • Report View, Data View, and Model View — when to use each
  • Connecting to Excel and CSV files Hands-on
  • Your first chart: Bar, Line, and Pie visuals
  • Formatting visuals: colors, fonts, titles, borders Hands-on
02
Data Transformation with Power Query
Week 2–3 · 7 lessons
  • Introduction to Power Query Editor
  • Removing duplicates, filtering rows, handling null values Hands-on
  • Changing data types: text, number, date, boolean
  • Splitting columns, renaming, and reordering Hands-on
  • Merging queries (equivalent of SQL JOIN) Hands-on
  • Appending queries to combine tables
  • Understanding Applied Steps and the M language (overview)
03
Data Modeling & DAX Basics
Week 3–4 · 8 lessons
  • What is a data model? Fact vs dimension tables
  • Creating relationships between tables Hands-on
  • Understanding cardinality (one-to-many, many-to-many)
  • Cross-filter direction and when to use bidirectional
  • Introduction to DAX: measures vs calculated columns DAX
  • Core DAX functions: SUM, COUNT, AVERAGE, MIN, MAX Hands-on
  • CALCULATE — the most important DAX function DAX
  • IF, SWITCH, and conditional DAX logic Hands-on
04
Building Professional Reports
Week 5–6 · 7 lessons
  • Dashboard design principles: layout, color, whitespace
  • KPI cards, gauge charts, and matrix visuals Hands-on
  • Slicers, page filters, and visual-level filters Hands-on
  • Drill-through and drill-down navigation
  • Conditional formatting: color scales, data bars, icons
  • Bookmarks and buttons for report navigation
  • Mobile layout view — optimizing for phones Hands-on
05
Publishing, Sharing & Security
Week 7–8 · 6 lessons
  • Publishing reports to Power BI Service Hands-on
  • Workspaces, apps, and organizing reports
  • Sharing with links, embedding, and export (PDF / PPT)
  • Row-Level Security (RLS) — basics Hands-on
  • Scheduled data refresh and data gateway overview
  • Course recap + what's next (Intermediate roadmap)
